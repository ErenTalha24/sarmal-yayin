# Sarmal Dijital

İşletmeler için web sitesi ve WhatsApp yapay zeka randevu asistanı.

Bu depo yayın deposudur: vitrin sitesi ve üç çalışan demo burada durur.
Sözleşme, teklif ve satış metinleri gibi çalışma dosyaları ayrı ve özel bir
depoda tutulur.

- `index.html` — vitrin sitesi
- `dis-klinigi/` — diş kliniği demosu
- `guzellik-salonu/` — güzellik salonu demosu
- `otomasyon-demo/` — WhatsApp randevu asistanı demosu
